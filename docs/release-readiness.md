## 已知限制

- Sci-Hub 是需要显式启用的实验来源。站点无 PDF 链接、403 或人机验证可能导致自动获取失败；验证码由用户在浏览器中处理，之后可导入本地 PDF。
- 批量队列的暂停和未执行项仅保存在本次 GUI 会话。下载显示阶段状态，不显示字节进度，也不能强制中止活动网络任务。
- 新版会记录逐来源诊断；旧历史记录不会自动补全诊断事件，重新运行后才有详情。
